# File System Manager

Консольный файловый менеджер на C# и .NET 9. Позволяет просматривать каталоги,
читать текстовые файлы, копировать, перемещать, переименовывать и удалять файлы.
Проект вырос из лабораторной работы по объектно-ориентированному программированию.

## Запуск

Сборка и тесты проверены на .NET SDK 9.0.304.
Из корня репозитория:

```bash
dotnet run --project src/FileSystemManager.Cli
```

В приложении, например на macOS:

```text
connect /Users -m local
tree list -d 2
disconnect
exit
```

Вместо `/Users` можно указать абсолютный путь к своему каталогу.

## Команды

| Команда | Действие |
|---|---|
| `connect <path> -m local` | Подключиться к локальному каталогу |
| `disconnect` | Завершить подключение |
| `tree goto <path>` | Перейти в каталог |
| `tree list -d <depth>` | Вывести дерево с заданной глубиной |
| `file show <path> -m console` | Показать текстовый файл |
| `file copy <source> <destination>` | Скопировать файл по новому пути |
| `file move <source> <destination>` | Переместить файл по новому пути |
| `file rename <path> <name>` | Переименовать файл |
| `file delete <path>` | Удалить файл |
| `exit` | Выйти из приложения |

Пути могут быть абсолютными или относительными к текущему каталогу.
Текущий парсер разделяет аргументы по пробелам: пути с пробелами пока не поддерживаются.

## Устройство проекта

```text
src/
  FileSystemManager.Core/   # файловые операции, команды и состояние подключения
  FileSystemManager.Cli/    # консоль, парсер и обработчики команд
tests/
  FileSystemManager.Tests/ # тесты разбора команд
```

CLI ссылается на Core. В Core находятся интерфейс `IFileSystem`, реализация локальной
файловой системы и команды с единым методом `Execute`. В CLI ввод разбирается
парсером и проходит через цепочку обработчиков, которые создают нужную команду.

Использованы паттерны **Command**, **Chain of Responsibility** и фабрики для выбора
файловой системы и способа вывода. Сейчас реализованы локальная файловая система
и вывод в консоль; часть форматирования и консольного вывода остаётся в Core.

## Тесты

```bash
dotnet test FileSystemManager.slnx
```

Существующие тесты проверяют разбор названий и аргументов команд, пустой ввод
и строку из пробелов. Файловые операции пока не покрыты автоматическими тестами.
